# 魔王城 HR 2

你是魔王城的人事主管：招怪物员工，派他们进办公室赚钱，或上三条路守城。勇者一波波打来，钱和命都要算。

You run HR for the demon lord's castle: hire monster staff, send them to earn in the office or to hold three lanes, and make payroll every wave.

**▶ 开始玩：https://byranmd.github.io/demon-castle-hr-v2/**（手机竖屏或电脑浏览器）

## 怎么玩

- **面试**：开战前可能有怪物来应聘。右滑录用、左滑拒绝，也可以点按钮。招聘费马上扣，工资每波都要发。
- **派岗**：拖员工到另一格就能换岗，随时免费。
  - 办公室 3 格：干满一个周期才拿钱，每人每波最多领 2 次。
  - 战斗区 2 排 × 3 路：挡住敌人。
- **合成**：把员工拖到同种 1 星员工上合成 2 星，再选「财务主管」或「安保队长」。
- **守城**：敌人先打本路的守军，打穿了才扣城心。
- **输赢**：3 颗心全没 = 城破；发不出工资 = 破产；撑过 6 波（最后一波有 Boss）就赢。
- **财务小结**：每波结束看完再点继续。
- **魔王金库**：每局结束，期末金币 × 已过波数 / 6 存进金库（赢了全存）。
- **魔王城天赋**：用金库的钱升级 5 个天赋：招聘广告、双份简历、开张资金、休整室、员工培训；随时免费重新规划。新手先输几局很正常，存钱升级后会越来越稳。
- **存档**：进度存在这台设备的浏览器里；换设备或清除浏览器数据会归零。

## 做法

- React + TypeScript + Vite。规则引擎是纯函数：固定步长，随机数由种子决定，有规则测试和 Bot 平衡测试。
- 音效全部用 Web Audio 现场合成，没有音频文件。美术是一张图一件东西的单件素材。
- 这个仓库只放打包好的网页（GitHub Pages），源码不在这里。
